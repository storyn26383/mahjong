# 03 — 牌資料模型 + 入牌元件

**What to build:** 牌手喺聽牌頁（同日後計台頁）用一個 42 種牌面嘅 grid 入手牌。切換模式決定點落去嘅牌加入暗牌、吃、碰、明槓、暗槓定花；碰同槓點一下自動成組，吃點三張連續牌成組；每種牌夠 4 張就灰掉；點已入嘅牌或副露組即移除；有清空掣同張數計數；手牌 reload 後仍在。
