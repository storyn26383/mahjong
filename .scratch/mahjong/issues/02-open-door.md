# 02 — 開門頁

**What to build:** 牌手喺開門頁入 3 顆骰點數（每顆 1 至 6）同自己係莊／下家／對家／上家，頁面即時畫出俯瞰四面牌山嘅 SVG，我喺下方，標明莊家、高亮開門嗰面山同由右邊數起嘅第 N 墩，箭咀指攞牌方向，圖下有一句「開 X 家山，由右邊數第 N 墩」。

**Blocked by:** 01 — 項目骨架

**Status:** ready-for-agent

- [ ] 引擎開門函數：輸入 3 顆骰點數同我相對莊家嘅座位，輸出開門山方位（相對我）、墩數、攞牌方向
- [ ] 規則：總點數由莊家逆時針數定山，再由嗰面山右邊數同一點數嘅墩數
- [ ] 引擎測試覆蓋至少三個總點數（例如 5、10、17）乘四個座位
- [ ] 頁面改任何輸入即時更新，冇計算掣
- [ ] 骰點數只可以揀 1 至 6
- [ ] SVG 標莊家、高亮開門山同墩、箭咀方向，附文字說明
