# 04 — 聽牌分析

**What to build:** 牌手入齊 16 張後，聽牌頁即時列出聽咩牌，每張標明係邊張、嵌張、單吊定雙洞，同埋仍有幾多張未見。唔夠或超過 16 張時顯示提示；未聽時顯示「未聽」。

**Blocked by:** 03 — 牌資料模型 + 入牌元件

**Status:** ready-for-agent

- [ ] 引擎拆牌函數：判斷一堆暗牌加副露係咪成 5 組面子加 1 對將，並枚舉所有拆法
- [ ] 引擎聽牌函數：對 34 種牌逐一試，輸出聽牌列表，每項含牌、獨聽類型、剩餘未見張數
- [ ] 獨聽類型：聽牌集合只有一張時按拆法分邊張／嵌張／單吊，多過一張為雙洞
- [ ] 小螺絲一類多面聽唔算獨聽
- [ ] 剩餘張數 = 4 減自己暗牌同副露入面同一隻牌數量
- [ ] 引擎測試覆蓋：邊張、嵌張、單吊、雙洞、小螺絲、有副露、未聽、剩餘張數
- [ ] 頁面即時更新，唔夠或超過 16 張有提示，未聽有提示
