# 05 — 計台：手牌判定台種

**What to build:** 牌手喺計台頁揀胡嘅張牌、自摸或放槍、圈風、門風，頁面即時顯示台數明細表同總台數。門清、不求人、全求人、半求人、邊張、嵌張、單吊、平胡、碰碰胡、混一色、清一色、字一色、三／四／五暗刻、三元刻、小三元、大三元、門風刻、圈風刻、小四喜、大四喜、正花、花槓全部由手牌自動判斷。手牌唔成胡時顯示「唔胡」。

**Blocked by:** 04 — 聽牌分析

**Status:** done

- [x] 引擎台數函數：輸入手牌、胡嘅張牌、局面（本票只用自摸／放槍、圈風、門風），輸出明細列表同總台數，或「唔胡」
- [x] 台數表值按 spec 寫死喺一個常數表
- [x] 門清：冇吃碰明槓；暗槓唔破門清
- [x] 不求人 = 門清且自摸；全求人 = 暗牌只剩 1 張且放槍；半求人 = 暗牌只剩 1 張且自摸
- [x] 獨聽台由聽牌分析結果自動判定
- [x] 平胡：無字、無花、無刻（含副露）、非獨聽、非自摸
- [x] 碰碰胡：五組全刻子或槓加一對將
- [x] 暗刻：暗牌刻子同暗槓；放槍完成嘅刻子當明刻，自摸完成嘅當暗刻
- [x] 正花按門風對應；花槓 2 另加夠套入面嘅正花 1
- [x] 大三元／小三元唔另計三元刻；大四喜唔加門風圈風刻，小四喜加
- [x] 一色、三元、四喜、暗刻、碰碰胡可以疊
- [x] 引擎測試：每個台種至少一個正例，加唔胡案例
- [x] 頁面：胡嘅張牌選擇器、自摸／放槍、圈風、門風，明細表同總台即時更新
